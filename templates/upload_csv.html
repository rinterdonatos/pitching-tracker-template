How to format your CSV / Excel file (click to view)

Using Excel? Build your sheet normally, then use File → Save As → CSV (Comma delimited). Only .csv files can be imported.

Row 1 must be column headers. Each row below it is one player's stats for one date. Column names are matched case-insensitively, and spaces/underscores don't matter.

ColumnRequired?Notes
Player (or Name)RequiredMust match a roster name exactly (capitalization doesn't matter). Rows with unrecognized names are skipped.
DateRecommendedAccepted formats: 2026-08-04, 8/4/2026, 8/4/26, Aug 4, 2026. If missing, today's date is used.
Strikes + PitchesOptionalInclude both and Strike % is calculated automatically. ("Total Pitches" and "Pitch Count" also work.)
IP + EROptionalInclude both and ERA is calculated automatically (scaled to 7-inning games). Use baseball IP notation: 5.1 = 5⅓ innings. Don't add your own ERA column - it's recomputed.
IP + K (or SO)OptionalInclude both and K/7 is calculated automatically.
Any other numeric columnOptionalBB, HBP, drill scores, spin rate - anything numeric gets tracked and charted automatically. % signs and commas are fine.

Pitch velocity: one column per pitch the player throws (only include pitches they actually throw). Any column name containing "Velo" gets charted on the player page, so "FB Velo", "FB Top Velo", and "Max Velo" all work:

Each session type has its own typical layout. Only Player and Date are always the same - the stat columns change with what you're tracking:

Bullpen - pitch counts, strikes, and the top velo on each pitch type thrown:

PlayerDatePitchesStrikesFB Top VeloSL Top VeloCH Top Velo

Pulldown - just the max velo:

PlayerDateMax Velo
Jake Thompson2026-08-0488.4

Game - the box score line; ERA and K/7 get computed from IP + ER + K:

PlayerDateIPERKBBHPitchesStrikesFB Velo

Live ABs - like a bullpen but against hitters, so results count too:

PlayerDatePitchesStrikesOutsHitsWalksFB VeloSL Velo
Jake Thompson2026-08-04241642184.875.0

Don't want to make the file yourself? Use the Build a CSV tool below the upload form - it sets up the right columns for each session type automatically.

Blank cells (or NULL, N/A, -, none) are simply skipped - they won't record a zero. Sample files are in the sample_data/ folder.
